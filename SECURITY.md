# Security Policy

## Supported Versions
We currently provide security updates for the following versions:

| Version | Supported          |
| -------- | ------------------ |
| Latest release | ✅ |
| Previous release | ⚠️ Limited |
| Older versions | ❌ Not supported |

---

## Reporting a Vulnerability
If you discover a security vulnerability, please **do not open a public issue**.

Instead, report it directly to our security team at:

📧 **security@turbotenant.com**

Please include:
- A detailed description of the issue.
- Steps to reproduce (if possible).
- Any potential impact or exploit scenario.

We aim to acknowledge receipt of your report within **48 hours**, and will provide regular updates until resolution.

---

## Disclosure Policy
We follow a responsible disclosure approach:
- Vulnerabilities are privately triaged and resolved before public disclosure.
- Credit will be given to reporters upon request.
- We coordinate disclosure timing to protect all users.
